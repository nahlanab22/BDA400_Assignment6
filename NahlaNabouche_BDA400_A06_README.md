## Project description
This project is an interactive stock portfolio dashboard built with R Shiny.
It downloads MSFT historical prices from Yahoo Finance using the quantmod
package and shows them as a line, area or candlestick chart. Users can choose
a date range and a daily, weekly or monthly time frame. Moving averages (SMA 20
and SMA 50), RSI and MACD can be switched on and off. A moving average
crossover rule generates Buy, Sell and Hold signals, and the Buy and Sell
signals are labelled on the chart.
